# Aktien-Cockpit

Privates Aktien-Dashboard für Verbio, Nordex und CTS Eventim: Live-Ticker, Charts, Technik-Rating, Kennzahlen, News, Insider-Links, Trade-Simulator mit Übungsdepot sowie Rechner für Knock-Outs und Positionsgrößen.

Dazu die Themen-Watchlist **Magnete & Seltene Erden** (MP Materials, Neo Performance, Lynas, Sprott REXC) mit eigenen Detailseiten, Zahlen-Terminen, Rohstoffpreis-Quellen und Risiko-Checkliste.

Kurse, Charts & Kennzahlen: [TradingView](https://de.tradingview.com/)-Widgets · Insider-Meldungen: [BaFin](https://portal.mvp.bafin.de/database/DealingsInfo/)

**Kein Anlage-, Rechts- oder Steuerberatungs-Tool.** Alle Angaben ohne Gewähr.
